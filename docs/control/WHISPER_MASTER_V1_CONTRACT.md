# WHISPER_MASTER_V1_CONTRACT

## Текущее техническое состояние (runtime)

### Реализованные действия Мастера шёпота
- `quiet_support` — тихая поддержка
  - В коде: `POST /player/last-whisper/action/{player_id}`
  - Требует `target_house_id` (другой дом), даёт целевому дому `+1 влияние`.
- `crown_tax` — налог на корону
  - В коде: `POST /player/last-whisper/action/{player_id}`
  - Ищет текущего единственного лидера влияния и пытается снять с него `-1 влияние`.
- `break_alliance` — разрыв союза
  - В коде: `POST /player/last-whisper/action/{player_id}`
  - Разрывает только существующий союзный `deal` из состояния `alliance_active` и фиксирует текст в `offer.break_text`.

### Текущая видимость в `player_room`
- Блок `Последний Шёпот` есть у всех, но активен только если `last_whisper` фаза.
- Действия доступны только если роль игрока `whisper_master`.
- Условие для активных действий: `viewer_can_act === true` и роль `whisper_master`.
- Важное ограничение: у дома может быть только одно действие за окно — если уже был ход, показывается статус «Ход уже сделан».
- Для не-мастера: виден только информационный статус, без кнопок.
- Блок скрытых сведений (`Сведения Мастера шёпота`) строится через `whisper_feed` только для роли `whisper_master`.

### Видимость на Master/TV
- Событие последнего шёпота прокидывается в общую сводку:
  - `last_whisper.latest_event` в сборке состояния игрока.
  - `_build_recent_events_payload` добавляет `last_whisper` как event типа `last_whisper`.
  - Появляется на TV/Master ленте как читабельный `action_label` + `tv_text`.

### Фрикции и слабые места (для V1)
- Низкая активность роли: окно открывается только на фазе `last_whisper`.
- «Одноразовость» в фазе (один шаг на дом) делает роль эпизодической и часто незаметной.
- `crown_tax` может быть безэффектным (лидер не найден или влияние не изменилось), но это не всегда явно объяснено игроку заранее.
- `break_alliance` зависит от существующих активных союзов, что делает действие нереализуемым в ряде игр без подготовки.
- Тонкие роли и шаблонные тексты в интерфейсе (включая сообщения «в следующих версиях…») снижает ощущение полноты роли.

## Предлагаемый V1 контракт (договорённость до патча)

### 1) Когда фаза активна
- Все действия Мастера шёпота доступны только во время активной фазы `last_whisper`.
- Вне фазы: блок показывается как информационный без действий.

### 2) Ограничение по количеству действий
- По умолчанию V1: **один ход на дом за одно окно `last_whisper`** (текущее поведение).
- Повторное действие в этой фазе блокируется сервером (`viewer_has_acted`), с явным сообщением.

### 3) No-op правила `crown_tax`
- Шаг валиден только если есть явный единственный лидер влияния (вызов `_get_single_influence_leader`): если лидер не определён (поворот/ничья), действие отклоняется с объяснением.
- Если лидер определён, но изменение `влияние` невозможно (`actual_delta != -1`, обычно из-за ограничения ресурса), действие считается выполненным, но без выгоды; событие формируется как сообщение «влияние не изменилось».
- Для V1 контракт это фиксируется как **“может быть без эффекта”** и требует явного пояснения в тексте результата.

### 4) Требования для `break_alliance`
- Валидация по серверу:
  - есть активные союзы в игре;
  - `target_deal_id` корректен и существует;
  - выбранная сделка имеет `status = alliance_active` и тип `alliance`.
- Иначе действие блокируется с причиной (нет союзов/неверный выбор/не тот статус).
- На успешном выполнении сделка переводится в `alliance_broken` и запись события сохраняется в историю `phase.payload`.

### 5) Ограничения `quiet_support`
- `target_house_id` обязателен и должен быть другим домом (`target != actor house`).
- Целевой дом должен принадлежать той же игре.
- На валидном вызове: `+1 влияние` целевому дому и добавляется скрытая заметка в фазе.

## Предлагаемая правка игрокоориентированного текста (без runtime-правок сейчас)
- В карточке роли заменить сообщение «В следующих версиях появятся» на короткий, уверенный гайд:
  - «Вы ведёте политические ходы в окне `Последнего шёпота`.
- В окне шёпота для мастера явно показывать:
  - что каждое действие можно сделать только один раз;
  - почему `налог на корону` может не сработать; 
  - какие союзы доступны прямо сейчас для разрыва.
- Для не-мастера текста убрать впечатление “ничего для вас” и показывать состояние активности окна только как инфо для другого игрока.

## Возможные кандидаты для следующего маленького runtime-патча (после утверждения контракта)
- Явное отображение причины no-op для `crown_tax` в результате операции и в блоке действий.
- Дополнительные подсказки в `lastWhisper` интерфейсе: список недоступных/доступных причин (`нет лидера`, `нет союзов`, `уже использовано`).
- Повторное применение `crown_tax` с защитой/информированием, если лидеру уже нельзя уменьшить влияние.
- Лёгкое уплотнение текста действий, чтобы роль ощущалась как «реальный политический рычаг», а не placeholder.
