# PRISTOLOV_CORE: локальный load-smoke на 10-15 участников

## 1. Назначение

Это чеклист локальной, не-LIVE репетиции для 10-15 участников.

Цель: заранее найти зависания, сломанные экраны, проблемы с назначениями и ролями, ошибки на телефонах и операторскую путаницу.

Это не production deploy и не работа с `LIVE01`.

Комната для текущей проверки: `TEST_ROOM_SETUP`.
Вопросный раунд: `QUESTION_DRYRUN_02`.

## 2. Нужные роли и устройства

- [ ] 1 ноутбук Мастера / оператора.
- [ ] 1 экран телевизора с браузером.
- [ ] 10-15 телефонов игроков.
- [ ] Как минимум один `Мейстер`.
- [ ] Как минимум один `Мастер над золотом`.
- [ ] Как минимум два `Лорд / Леди Дома` или обычных игрока.
- [ ] Опционально: отдельное устройство Кассира / оператора золота.

## 3. Предварительная проверка

- [ ] Рабочее дерево Git чистое.
- [ ] Работает локальный сервер.
- [ ] Используется только локальная база.
- [ ] Не открыт production URL.
- [ ] Не используется `LIVE01`.
- [ ] Телевизор подключен и показывает нужный браузер.
- [ ] Телефоны находятся в доступной для локального сервера сети.
- [ ] QR-код или ссылки для входа готовы.
- [ ] Зарядки или power bank готовы.
- [ ] Есть бумажный список запасных имён Домов и игроков.
- [ ] Активная тестовая комната определена.
- [ ] Текущее состояние тестовой комнаты записано: `TEST_ROOM_SETUP`, активный раунд `QUESTION_DRYRUN_02`, вопрос 2 активен, ответы закрыты.

## 4. Фазы smoke-проверки

### Фаза A: вход, подключение и страницы игрока

- [ ] 10-15 участников открыли свои ссылки игрока.
- [ ] Страницы загрузились без `500` и traceback.
- [ ] Имена и Дома видны.
- [ ] Обновление страницы работает.
- [ ] Никто не оказался в чужом Доме.
- [ ] Мобильная верстка приемлема.

### Фаза B: базовая проверка Master и TV

- [ ] Экран Мастера открылся.
- [ ] TV mode открылся.
- [ ] Текст на TV читаем с расстояния.
- [ ] Нет mojibake и битой кириллицы.
- [ ] Нет пропавших статических файлов.
- [ ] Макет не распадается при обновлении.

### Фаза C: поток вопросов Question Bank V2

- [ ] Активирован текстовый вопрос из `QUESTION_DRYRUN_02`.
- [ ] Мастер видит вопрос.
- [ ] TV видит вопрос.
- [ ] `Мейстер` получает назначение.
- [ ] Не-Мейстеры ведут себя ожидаемо и не получают чужое назначение.
- [ ] Ответ закрыт до предусмотренного момента.
- [ ] Показ ответа не ломает TV.
- [ ] Следующий вопрос открывается хотя бы один раз.

### Фаза D: контур золота, Мастера над золотом и Кассира

- [ ] Мастер над золотом открывает нужный экран.
- [ ] Баланс золота виден.
- [ ] Проверена простая операция с золотом или безопасный dry path.
- [ ] Экран Кассира / dev gold открывается, если он используется.
- [ ] Нет случайной production-транзакции.
- [ ] Реальная покупка в Харчевне не выполняется, если она не была отдельно намеренно смоделирована.

### Фаза E: контур дуэли

- [ ] Создана или смоделирована безопасная дуэль только в не-LIVE комнате.
- [ ] Мастер видит дуэль.
- [ ] Участники дуэли видят ожидаемое состояние.
- [ ] Путь победителя работает, если он проверяется.
- [ ] Статус ничьей и повторного розыгрыша отображается, если они проверяются.
- [ ] В ветке ничьей нет случайной награды.

### Фаза F: контур Харчевни и магазина

- [ ] Экран магазина / Харчевни открывается, если применимо.
- [ ] Одобренные позиции видны, если применимо.
- [ ] Нет автоматической замены, возврата или подстановки.
- [ ] Реальная операция бара не выполняется без отдельного ручного согласования.

### Фаза G: поведение под нагрузкой

- [ ] 10-15 участников одновременно обновили страницы.
- [ ] TV остался отзывчивым.
- [ ] Мастер остался отзывчивым.
- [ ] Страницы игроков восстановились после обновления.
- [ ] Нет повторной путаницы с login или localStorage.
- [ ] Нет заметной серии серверных ошибок.

## 6. Условия остановки

Остановить smoke и зафиксировать результат, если:

- появляется production URL;
- появляется `LIVE01`;
- требуется миграция базы;
- сервер начинает повторно отдавать `500`;
- Мастер не может управлять игрой;
- TV нечитаем или сломан;
- игроки не могут загрузить страницы;
- вопрос не раскрывается на Master или TV;
- назначение `Мейстеру` не работает после контролируемой настройки;
- операция золота выглядит небезопасной;
- появляется риск случайной реальной покупки или оплаты.

## 7. Критерии PASS

- [ ] 10-15 телефонов загрузили страницы игроков.
- [ ] Мастер может работать с экраном.
- [ ] TV пригоден для игры.
- [ ] Хотя бы один вопрос раскрылся на Master и TV.
- [ ] Назначение `Мейстеру` работает.
- [ ] Восстановление после обновления приемлемо.
- [ ] Production и `LIVE01` не использовались.
- [ ] Нет проблемы уровня `blocker`.
- [ ] Все проблемы уровня `major` и `minor` записаны.

## 8. Решение после smoke

Выбрать один итог:

- `GO` с известными minor-проблемами.
- `GO` с операторским workaround.
- `FIX BEFORE GAME`.
- `NO-GO` до устранения blocker.

## 9. Правила безопасности

- Не использовать production.
- Не использовать `LIVE01`.
- Не выполнять deploy.
- Не выполнять миграции.
- Не выполнять реальную оплату или бар-транзакцию без отдельного согласования.
- Не импортировать дополнительные вопросы во время load-smoke.
- Все действия остаются локальными и не-LIVE.

После завершения зафиксировать журнал проблем и итоговое решение; не начинать исправления «на эмоциях» без отдельной оценки приоритета.
