## Approval checklist

Before approving, confirm:

- action targets a Дом, not a real person;
- action is understandable in one sentence;
- action does not create automatic penalty;
- action does not secretly and irreversibly harm another House;
- action does not move gold/influence/resources automatically;
- action does not affect staff/legal/bar decisions;
- repeated targeting is not becoming unpleasant;
- all involved Houses understand whether the deal is public or private;
- charge is spent only if host approves and resolves the action.

## Quick result vocabulary

Approved:

- “Принято.”
- “Принято, но я переформулирую.”
- “Принято как публичный слух.”
- “Принято как приватная разведка.”

Rejected:

- “Отклонено: цель должна быть Домом, не человеком.”
- “Отклонено: слишком сильный эффект для V1.”
- “Отклонено: это создаёт автоматическое наказание.”
- “Отклонено: это тормозит игру.”

No charge spent:

- host rejects before resolution;
- host says timing is wrong;
- player withdraws action before host resolves.

Charge spent:

- host approved and resolved Разведка;
- host approved and announced/used Слух;
- host approved and answered Тень сделки.
