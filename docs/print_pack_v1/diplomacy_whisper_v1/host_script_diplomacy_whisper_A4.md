# Host script: Diplomacy + Whisper V1

## Before Diplomacy starts

“Сейчас будет Дипломатия. Это не пауза. Это время договориться, кого поддержать, кого сдержать и кому можно верить.”

“Дипломаты могут двигаться и говорить с другими Домами. Лорд / Леди Дома подтверждает важные обещания.”

“Сделка становится игровой правдой только когда её подтвердили участники и ведущий.”

## Explain deal cards

“У вас есть простые типы договорённостей: союз, поддержка в Суде, обещание не атаковать, обмен информацией, давление на третий Дом и золотая помощь как ручное обещание.”

“Эти карточки не запускают автоматику. Они помогают всем говорить на одном языке.”

“Если обещание связано с золотом, это отдельно подтверждает Мастер над золотом и ведущий/оператор.”

## Explain Whisper charges

“У каждого Дома есть 3 заряда шёпота. Их использует Мастер над шёпотом.”

“Шёпот не ломает игру. Он создаёт давление: узнать, намекнуть, посеять сомнение.”

“Любой шёпот подтверждает ведущий. Если действие тормозит игру или портит атмосферу, ведущий его отклоняет.”

## Explain no hidden math arguments

“Мы не спорим о скрытой математике. Ведущий даёт только разрешённый результат: примерный уровень, безопасный слух или короткий ответ по политической связи.”

“Точные числа, формулы и закрытые расчёты не раскрываются через спор за столом.”

## Safe rumor announcements

Use these formats:

- “По залу пошёл слух: Дом ________ слишком быстро набирает влияние.”
- “Говорят, союз ________ и ________ не так крепок.”
- “Шёпот намекает: кто-то готовит сделку против лидера.”
- “В кулуарах говорят, что Дом ________ ищет поддержку перед Судом.”

Avoid:

- insults;
- real-person accusations;
- personal traits;
- harassment;
- exact hidden numbers;
- legal/staff/bar promises;
- automatic punishment wording.

## Prevent abuse

If one House is targeted repeatedly:

“Стоп. Один Дом уже получил достаточно давления. Следующий шёпот должен выбрать другую цель или другой формат.”

If rumor becomes personal:

“Переформулируем. В игре мы давим на Дома, не на людей.”

If players argue that a card must force an effect:

“Нет. V1 работает вручную. Карта — это заявка ведущему, не автоматический закон.”

If someone asks for automatic penalty:

“Автоматических штрафов нет. Ведущий может дать только ручной, безопасный эффект.”

## Quick stage close

“Дипломатия закрывается. Зафиксируйте последние обещания. Шёпоты, которые не подтверждены ведущим, не считаются игровым эффектом.”

“Сейчас важны не только очки, но и то, кому зал верит.”
