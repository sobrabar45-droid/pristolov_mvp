# Diplomacy + Whisper V1 print pack

This pack is a manual test kit for the political layer before any runtime implementation.

Use it when the host wants to test stronger Diplomacy and `Мастер над шёпотом` agency during a live or rehearsal game.

## What is inside

- `whisper_charge_cards_A4.md` — charge cards for `Мастер над шёпотом`.
- `diplomacy_deal_cards_A4.md` — manual Diplomacy deal cards.
- `host_resolution_sheet_A4.md` — host tracking sheet.
- `host_script_diplomacy_whisper_A4.md` — short host script and safety copy.

## What to print

For up to 10 Houses:

- Player explanation: 1 copy per House + 1 copy for host.
- Whisper charge cards: enough for 3 charges per House, 30 charges total for 10 Houses.
- Whisper action cards: at least 1 set per House, or 2-3 shared table sets if cutting time is limited.
- Diplomacy deal cards: 2-3 shared table sets minimum; print more if many Houses will negotiate at once.
- Host resolution sheet: 2-3 copies for host.
- Host script: 1 copy for host.

Recommended format:

- A4 paper.
- Large font, 14-18 pt if re-laid out.
- Cut cards after printing.
- Use colored paper or marker dots for Whisper charges if available.

This is a manual playtest kit. It does not add a runtime feature by itself.

## What this tests manually

- Whether Diplomacy feels like a real stage, not a pause.
- Whether players understand what a deal/promise can be.
- Whether `Мастер над шёпотом` feels active before the final window.
- Whether 3 charges per House is too many, too few, or just right.
- Whether `Разведка`, `Слух`, and optional `Тень сделки` are understandable at a noisy table.

## What must not be automated yet

Do not automate yet:

- Whisper charge counters.
- Automatic resource changes.
- Automatic penalties.
- Automatic deal breaking.
- Secret irreversible effects.
- Full attack/defense engine.
- New resource system.
- Private messaging system.

V1 is manual and host-confirmed.

## Safety rules

- Host may approve, rewrite, or reject every Whisper action.
- No action targets real people personally; target Houses only.
- No harassment, insults, or repeated pressure without host approval.
- No automatic gold/influence/resource changes.
- No automatic deal break.
- No hidden automatic penalties.
- Staff/legal/bar decisions cannot be affected by Diplomacy or Whisper.

## Suggested table flow

1. At the first Diplomacy window, host explains deal cards.
2. Each House receives 3 Whisper charges.
3. Only `Мастер над шёпотом` may spend Whisper charges.
4. A charge is spent only after host approves the action.
5. Host records every approved/rejected action on the resolution sheet.
6. After the game, host reviews which cards created useful drama and which were confusing.
