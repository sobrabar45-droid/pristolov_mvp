# Action card: Разведка

Role: Мастер над шёпотом

Cost: 1 заряд

Target: one House

Player writes/says:

- “Хочу разведать Дом ________.”
- Choose one: золото or влияние.

Host confirms:

- target is a House, not a person;
- same House is not being repeatedly pressured too much;
- timing is acceptable.

Host answer:

- approximate tier only, not exact numbers.

Example gold tiers:

- мало золота
- средне золота
- много золота

Example influence tiers:

- слабое влияние
- среднее влияние
- сильное влияние

What happens:

- acting House receives approximate information.
- no automatic resource change.
- no public penalty.

Risk note:

- repeated targeting can feel oppressive; host may reject repeat use.

# Action card: Слух

Role: Мастер над шёпотом

Cost: 1 заряд

Target: one House, one alliance, or one public situation

Player writes/says:

- “Хочу пустить слух: ________.”

Host confirms:

- rumor targets a House/action, not a real person;
- wording is playful, not insulting;
- rumor does not reveal hidden exact math;
- rumor does not create automatic penalty.

Host may:

- approve as written;
- rewrite safely;
- reject;
- announce publicly;
- announce semi-publicly.

What happens:

- host announces a short approved rumor.
- no automatic penalty.
- no automatic resource change.

Safe examples:

- “По залу пошёл слух: Дом ________ слишком быстро набирает влияние.”
- “Говорят, союз ________ и ________ не так крепок.”
- “Шёпот намекает: кто-то готовит сделку против лидера.”

Risk note:

- no personal insults, no harassment, no repeated pile-on.

# Action card: Тень сделки (optional/test)

Role: Мастер над шёпотом

Cost: 1 заряд

Target: one House

Player writes/says:

- “Хочу узнать, есть ли у Дома ________ политическая связь.”

Host confirms:

- timing is acceptable;
- target is a House;
- action will not expose private details beyond V1 limits.

Host may answer:

- “Есть явная политическая связь.”
- “Явной связи не видно.”
- “Ответ слишком рано раскрывать; заряд не тратится.”

What happens:

- acting House may learn whether target House has active political ties.
- no details unless host allows.
- no automatic deal break.
- no automatic penalty.

Risk note:

- keep this optional until host is comfortable running it.
