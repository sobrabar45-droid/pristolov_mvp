# Diplomacy deal cards A4

Print and cut. These cards are manual promises for Diplomacy windows.

В V1 нет автоматического исполнения. Ведущий может только вручную трактовать последствия договорённости в рамках игры.

---

# Deal card: Союз до следующего этапа

Houses involved:

- Дом ________
- Дом ________

Promise:

- We publicly agree to cooperate until the next stage.

Duration:

- until the next stage starts, unless host extends it.

Public/private:

- public by default.

Host confirmation:

- both Houses agree;
- Лорд / Леди Дома approve;
- host may announce.

Betrayal:

- allowed only as social drama unless host sets a special rule.

Enforcement:

- no automatic enforcement.

Notes:

- Best for making Diplomacy visible to the room.

---

# Deal card: Поддержка в Суде

Houses involved:

- supporting House: ________
- supported House: ________

Promise:

- We promise public support in Court.

Duration:

- until the next Court pair or Court cycle.

Public/private:

- public or semi-public; host chooses.

Host confirmation:

- both Houses understand this is a promise, not an automatic bonus.

Betrayal:

- allowed socially; host may announce broken promise if dramatic.

Enforcement:

- no automatic Court advantage.
- no automatic influence/gold change.

Notes:

- Do not use this as a hidden Court modifier in V1.

---

# Deal card: Обещание не атаковать

Houses involved:

- Дом ________
- Дом ________

Promise:

- We promise not to target/challenge each other for one stage.

Duration:

- one stage or until host announces expiry.

Public/private:

- public is recommended.

Host confirmation:

- both Houses agree what “attack” means for this game.

Betrayal:

- allowed only if host allows betrayal drama.

Enforcement:

- no automatic block.
- host may remind players of the promise.

Notes:

- Use carefully; do not freeze the whole game.

---

# Deal card: Обмен информацией

Houses involved:

- Дом ________
- Дом ________

Promise:

- We exchange information, hints, or political reads.

Duration:

- immediate or until end of Diplomacy window.

Public/private:

- private/social by default.

Host confirmation:

- not required unless players want it official.

Betrayal:

- allowed; information may be false unless host says it is official.

Enforcement:

- no automatic enforcement.

Notes:

- Host should distinguish player claims from system truth.

---

# Deal card: Давление на третий Дом

Houses involved:

- Дом ________
- Дом ________

Target House:

- Дом ________

Promise:

- We coordinate politically against the target House.

Duration:

- one stage or until host announces expiry.

Public/private:

- public or semi-public.

Host confirmation:

- host checks that pressure stays playful and House-targeted.

Betrayal:

- allowed socially.

Enforcement:

- no automatic penalty to target House.

Notes:

- Host should prevent repeated pile-on against one House.

---

# Deal card: Золотая помощь (social/manual promise only)

Houses involved:

- helping House: ________
- receiving House: ________

Promise:

- We promise gold-related help or bar/social support.

Duration:

- immediate or one stage.

Public/private:

- host chooses.

Host confirmation:

- if real gold movement is involved, Мастер над золотом and operator/cashier must confirm separately.

Betrayal:

- allowed socially unless host sets a special rule.

Enforcement:

- no automatic gold transfer.
- no automatic resource mutation.

Notes:

- Use as a social promise first. Do not create accounting arguments at the table.
