# PRISTOLOV print pack V1

This folder contains print-ready Markdown source files for the next live PRISTOLOV game.

Open each file in a Markdown editor/browser preview and print on A4. These are source layouts, not final graphic-design PDFs.

## Pack contents

| File | What it prints | Recommended quantity | Use |
|---|---|---:|---|
| `player_one_page_rules_A4.md` | One-page player rules | 120 | Hand to players before start |
| `house_table_markers_A4.md` | 10 House table markers | 1 full set + 2 blank spares later | Place on House tables |
| `role_cards_A4.md` | Role cards/badges for all roles | 110 role cards + 20 blanks later | Give after role assignment |
| `host_seating_map_A4.md` | Blank host seating map | 3 | Host/operator clipboard |
| `screen_frozen_cards_A4.md` | Small screen-help cards | 20 | Tables, host, cashier, helpers |
| `host_quick_script_A4.md` | Short host script | 3 | Host/moderator desk |

## Print checklist

- Print player rules first: they are the highest-impact disposable item.
- Print House markers on thicker paper if possible.
- Print role cards on thicker paper or sticker sheets if available.
- Print host seating map on A3 if possible; A4 is acceptable.
- Print emergency screen cards and cut them into small cards.
- Keep 10-20 blank role cards and 2 blank table markers for emergencies.

## Reusable / disposable

Reusable:

- laminated House table markers;
- laminated host seating map template if used with erasable marker;
- lanyard badge holders.

Disposable:

- player one-page rules;
- role stickers/cards if written on;
- screen frozen cards;
- event-specific host quick script.

## Paper and finishing

Recommended:

- player rules: A4, normal paper, 14-16 pt body equivalent;
- House markers: A4 or A5, thick paper, laminate if possible;
- role cards: A6 or badge-card size, thick paper/stickers;
- host map: A3 preferred, A4 acceptable;
- emergency cards: A6 or quarter-A4.

Laminate:

- House table markers;
- reusable host seating map;
- reusable role cards if not personalized.

Cut:

- role cards;
- screen frozen cards;
- optional host quick script copies are not cut.

## Handout flow

1. Before registration: prepare House markers, role cards, host map, emergency cards.
2. At entrance or table seating: hand out player rules.
3. After House creation: place the House table marker.
4. After role assignment: hand out role cards/badges.
5. Before start: host reads the quick script.
