# Карточка «Создать Дом» (One QR)

- Title: **Создать Дом**
- Subtitle: **Сканирует Лорд / Леди Дома**
- URL: `https://pristolov.ru/delegation/start?game_code=LIVE01&entry_mode=random`
- Примечание по экономике: **500 ₽ = 1 золото**
- Примечание по жребию: **Жребий даёт +1 золото**

## Что печатать

1. Разместить QR в центре карточки.
2. В блоке под заголовком вывести:
   - Сканируйте QR
   - Создайте Дом
   - Выберите Дом сами или доверьтесь жребию
   - Жребий даёт +1 золото
   - Отправьте ссылку игрокам своего Дома
3. Под списком указать:
   - URL: https://pristolov.ru/delegation/start?game_code=LIVE01&entry_mode=random
   - Роль: Лорд / Леди Дома
