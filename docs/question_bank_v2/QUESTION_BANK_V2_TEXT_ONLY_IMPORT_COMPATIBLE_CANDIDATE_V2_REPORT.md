## 6. Parser compatibility

Read-only проверка через `parse_questions_xlsx`:

```text
PARSED_COUNT 19
ERROR_COUNT 0
TYPE_COUNTS {'true_false': 13, 'single_choice': 6}
```

Команда из задания ожидала объектные атрибуты `q.errors` и `q.question_type`, но текущий parser возвращает словари с ключами `errors` и `type`. Поэтому после частичного результата `PARSED_COUNT 19` проверка была повторена с фактическим контрактом текущей функции. Endpoint `/dev/questions/import` не вызывался.
