# Суд Домов — ручной банк вопросов

## Цель документа

Этот документ — **ручной хост-модуль** для проведения Суда Домов, если вопросы не импортированы в runtime и нужно провести блок полностью вручную.

Он собирает:
- безопасный порядок парингования Домов,
- понятные правила по нечётному числу Домов,
- готовые формулировки фраз ведущего,
- 45 вопросов из ручного банка: 35 основных + 10 резервных (тай-брейк).

## Источники

- `docs/control/COURT_PAIRING_AND_REWARD_LOGIC_AUDIT.md` — результаты аудита runtime.
- `docs/control/LIVE01_QUESTION_REPLACEMENT_CANDIDATES_DRAFT.md` — 45 чистых вопросов (чистый основной + резерв).
- `docs/manuals/MODERATOR_PRINTABLE_CHEATSHEET_PRISTOLOV.md` — общие правила модератора и роли.

## Емкость и рамки

- Поддерживает до 10 Домов.
- При 10 Домах: 5 пар.
- Для покрытия до 5 пар с запасом минимум нужно 35 вопросов.
- В данном документе: **35 основных + 10 резервных = 45 вопросов** (соответствует минимальной и безопасной цели).
- Играет курс золота: **500 ₽ = 1 золото** (для справки ведущего).

## Правило пары Суда Домов

### Ранжирование Домов перед Судом Домов

1. **Влияние (`influence`) — выше лучше**
2. **Золото (`gold`) — выше лучше**
3. **При равенстве — порядок жеребьёвки ведущего**

### Формирование пар

После ранжирования Домов по вышеуказанным критериям:

- 1 vs N  
- 2 vs N-1  
- 3 vs N-2  
- и так до центра.

### Нечётное число Домов

Если Домов нечётное количество:
- **первый круг** получает пропуск (bye) средний по рангу Дом;
- остальные Дома формируют пары по правилу «от краёв к центру».

Примеры:
- 9 Домов: 1vs9, 2vs8, 3vs7, 4vs6, **5 — пропуск**.
- 7 Домов: 1vs7, 2vs6, 3vs5, **4 — пропуск**.

## Вознаграждение после пары (важно)

По текущему аудиту runtime:
- автоматического начисления влияния/золота/очков по победе пары не предусмотрено;
- победители пар фиксируются **по решению ведущего** в ручном режиме.

Рекомендуемый принцип на живой игре:
- не обещать автоматические ресурсы из Суда Домов;
- если ведущий решает вручную выдать бонус — фиксировать это отдельным объявлением перед соответствующим блоком.

## Как вести одну пару вручную

1. Объявить пару.
2. Задать по 1–N вопросов в формате выбранной сессии:
   - фиксированное количество вопросов, или
   - «кто первым наберёт X».
3. При равенстве: использовать резервный вопрос-тайбрейк.
4. Записать победителя пары вручную в журнал ведущего/ведомую заметку.

### Фразы ведущего (рекомендуемые)

- «Сейчас начинается Суд Домов.»
- «Первый Дом встречается с последним, второй — с предпоследним.»
- «Если Домов нечётное количество, средний Дом по посеву проходит первый круг без пары.»
- «Победитель пары проходит дальше.»
- «Суд может перевернуть положение Домов.»

## Что **не** объяснять/не обещать

- Не использовать рольную терминологию, не подтверждённую текущими правилами.
- Не обещать скрытый/внешний ресурс по Суду Домов (если только хостом не объявлен отдельный ручной порядок).
- Не использовать завышенный/альтернативный курс; использовать только согласованный игровой курс для сессии.
- Не объяснять Герб/crest как активную механику в блоке Суда Домов.

## Что проверить перед запуском Суда Домов

1. Подготовить порядок Домов по влиянию и золоту.
2. Проверить сценарий на нечётное число Домов и определить средний Дом для bye.
3. Проверить, что у ведущего есть блокнот/таблица для ручной фиксации победителей.
4. Напомнить игрокам, что по итогам блока ресурсы выдаются только по отдельному решению ведущего.
