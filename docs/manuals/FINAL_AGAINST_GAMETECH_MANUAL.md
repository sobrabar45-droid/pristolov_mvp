# Финал — испытание игротехника

## 1) Ядро правила

В Финале участвует **один Дом** — победитель по итоговой таблице.  
Исключительно этот Дом проходит финальную дуэль.

Финал проходит не между двумя Домами, а как **испытание дома против игротехника**.

## 2) Как определяется Финалист

Финалист выбирается по текущей итоговой таблице:

1. `Влияние` (внутренняя итоговая величина),
2. `золото`,
3. дополнительный розыгрыш по решению ведущего (короткая жеребьёвка/мини-задача), если показатели равны.

Приоритеты важны: сначала `influence`, потом `золото`, затем вынесенный ведущим tie-break.

## 3) Почему это важно для всех Домов

Другие Дома продолжают влиять на итог даже без выхода в финал:

- политикой и дипломатией влияют на расстановку Домов;
- поддьяльные решения в Суде и дуэлях меняют итоговое положение;
- роль Лорда и ходовые действия в `Последний Шёпот` могут изменить порядок;
- общий результат влияет на силу и уверенность Финалиста.

Поэтому даже не дойдя до финала, Дом остаётся полезным участником с влиянием на победителя.

## 4) Сегодняшний ручной финальный fallback

**Формат на сегодня**: вопросы для **Финального Домa** против приглашённого игротехника.

- Финалист отвечает (или отвечает его Дом) на вопросы.
- Количество правильных ответов для победы выбирает ведущий перед стартом финала:
  - `1` — очень сильная/очевидная победа по состоянию к финалу;
  - `2` — обычная/контестная ситуация;
  - `3` — сложная/трудная борьба и много препятствий по ходу игры.
- Ведущий объявляет сложность до старта испытания на основе итогов партии.

**Победитель** финала — тот, кто первым выполнил требуемое число правильных ответов по принятому порогу.

## 5) Как объявлять финал (короткий скрипт)

- «Финал: один Дом остаётся в центре внимания — он проходит испытание у игротехника.»
- «Победитель определяется не вторым Домом, а по результату этого финального испытания.»
- «Выигрывает тот Дом, кто покажет лучшую игру/ответы под давлением.»
- «Сегодня сложность финала выбрал ведущий по итоговым показателям и текущему состоянию.»
- «Победивший Дом завершает вечер и получает итоговый статус победителя.»

## 6) Как это связано с Судом Домов

- Суд дома формирует очередность и может менять порядок Домов до финала.
- В финал попадает Дом с лучшим текущим положением по правилам выше (влияние → золото → tie-break).
- Резервного автоматического влияния/золота от финала в runtime не обещаем.

## 7) Что не говорить / ограничения

- Не говорить, что финал всегда между двумя Домами.
- Не обещать автоматические ресурсы в финале.
- Не использовать устаревшие/неактуальные термины и цифры для правил, которые не действуют в текущей игре.
- Если используется терминология финальной секции в сценарии, подчёркивать: это модульный блок, который может меняться.

## 8) Будущее и расширение

Рабочие названия для этой секции, которые можно чередовать по мероприятию: «Через тернии к престолу» / «Испытание игротехника».

Этот документ описывает сегодняшнюю рабочую схему.  
В других вечерах финал может быть:

- Армрестлинг,
- блиц в стиле шахмат,
- реакционная игра,
- дегустационное задание,
- иные форматы по решению автора события.

Для гостей формат должен оставаться **неизвестным заранее** — только объявляется в момент старта финала.

## 9) Быстрый чек-лист перед Финалом

- Убедиться в окончательной таблице Домов и выбранной методике tie-break.
- Выбрать порог победы (1/2/3) и объявить его перед стартом.
- Напомнить игрокам: победит только один Финалист против игротехника.
- Подготовить экран/звуковой поток для закрытия итогов и оглашения победителя.
