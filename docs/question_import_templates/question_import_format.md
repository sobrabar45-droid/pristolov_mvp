# Формат импорта вопросов

Эта папка содержит два шаблона для будущего импортёра вопросов:

- `pristolov_questions_template.docx` — удобный шаблон для ручного заполнения в Word
- `pristolov_questions_template.xlsx` — строгий табличный формат для массовой загрузки

## Общие правила

- Один вопрос должен быть заполнен полностью.
- Правильный ответ обязателен.
- Пояснение желательно заполнять всегда.
- Если у вопроса есть картинка, аудио или видео, указывайте тип медиа и ссылку/название.
- Медиа пока хранится отдельно: импортёр будет запоминать только ссылку, имя файла или условное название.

## Word

- Один вопрос начинается с номера: `1.`, `2.` и так далее.
- Вопросы разделены по секциям:
  - `ПРАВДА ИЛИ ПИЗДЁЖ?`
  - `ВАРИАНТЫ ОТВЕТОВ`
  - `ВОПРОСЫ БЕЗ ВАРИАНТОВ`
- Для стабильного импорта лучше всегда писать строку:
  - `Правильный ответ: ...`
- Дополнительно можно выделять правильный вариант курсивом.
- Если у вопроса нет медиа, пишите `Медиа: пусто`.

Пример структуры в Word:

```text
1. Текст вопроса?
- вариант А
- вариант Б
- вариант В
- вариант Г
Правильный ответ: вариант Б
Пояснение: короткое объяснение
Медиа: Фото Конкурс красоты
```

## Excel

- Один вопрос = одна строка.
- Рабочий лист должен называться `questions`.
- Колонки в шаблоне:
  - `section`
  - `question_type`
  - `question`
  - `option_a`
  - `option_b`
  - `option_c`
  - `option_d`
  - `correct_answer`
  - `explanation`
  - `media_type`
  - `media_ref`
  - `difficulty`
  - `role_code`
  - `round_code`
  - `tags`

### Допустимые значения

- `question_type`:
  - `true_false`
  - `single_choice`
  - `free_text`

- `media_type`:
  - `image`
  - `audio`
  - `video`
  - `none`

### Примеры media_ref

- `Фото Конкурс красоты`
- `Фото Русалочка`
- `audio_01.mp3`
- `image_kodak_1.jpg`

## Рекомендация

Если вопросы сначала собираются в Word, а потом переносятся в Excel, используйте одинаковые формулировки:

- один и тот же текст вопроса
- один и тот же правильный ответ
- одинаковое имя медиа

Так будущему импортёру будет проще сопоставлять данные без ручной правки.
